# CivicPlus Professional Frontend

A polished, Instagram/Snapchat-inspired community social platform frontend based on the supplied CivicPlus synopsis.

## Pages / flows
- Sign up / Login
- Home feed
- Explore / trending
- Notifications
- Messages
- Saved posts
- User profile
- Account / privacy settings
- Create post modal
- Photo/video selection preview
- Anonymous vs public posting
- Approximate location
- Temporary content controls
- Hype / Confirm / Discuss / Save interactions
- Responsive mobile navigation

## Run
Open `index.html` in Chrome/Edge/Firefox.

This is a frontend-only prototype. Authentication, database, real AI, metadata stripping, maps, moderation and real messaging need a backend/API implementation.
